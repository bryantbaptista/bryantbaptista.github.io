## Introduction to Bootstrap 5

For designing and creating straightforward web pages in ICS 314, I have been using HTML and CSS. Then, I was recently introduced to Bootstrap 5, a framework for building websites, and have been using it to create web pages for the past few classes. When I first saw Bootstrap 5 on the assignment page, I had no idea what it was. After reading through the documentation, it was a little confusing due to the different classes and components. However, after using it for several assignments, I saw why the frameworks were useful. Bootstrap 5 gives predefined classes, which makes it easier to organize layouts and spacing without having to write as much custom CSS from scratch.

## HTML and CSS to Bootstrap 5

When we first started making web pages, I found HTML and CSS to be tedious, and it felt like learning a new programming language. After we started using Bootstrap 5 for websites, it made it easier to create the navigation bars and organize the website contents. However, it did not completely replace the need to make custom CSS to match the original web designs that we were replicating. These assignments showed that Bootstrap 5 does not completely replace CSS but acts as a tool to make web development more efficient.

## Usefulness of UI Frameworks

Overall, I think that UI frameworks such as Bootstrap 5 are useful in software engineering and important to learn. Although you could design a website just fine with HTML and CSS on your own, Bootstrap 5 provides reusable components and responsive layouts while also maintaining consistency, which makes websites easier to update in the future. It also saves time, which is useful for larger projects and when collaborating with other software engineers. Although confusing at first for someone who is new to web design, I think that the time spent learning it will be worth it since it makes building websites more efficient and organized.
